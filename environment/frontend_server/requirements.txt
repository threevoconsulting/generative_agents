# Generative Agents -- environment (Django web) server requirements.

# of the authors' full research environment and pinned many analysis libraries
# (gensim, matplotlib, scikit-learn, ...) that the server never imports. Those
# are listed at the bottom for the record.

Django>=2.2,<2.3
channels>=2.4,<3             # WebSocket transport (Django 2.2 compatible)
# channels 2.x's HTTP handler is broken with asgiref >= 3.3: requests start
# failing with 500 "CurrentThreadExecutor already quit or is broken" (incl.
# static files, so the map never loads). See django/channels#1587 -- only
# fixed in channels 3. Keep asgiref below 3.3 as long as channels 2.x is used.
asgiref>=3.2,<3.3            # required by channels; MUST stay < 3.3
django-cors-headers>=2.5,<3.6   # 'corsheaders' app in INSTALLED_APPS
django-storages>=1.9,<1.13      # 'storages' app in INSTALLED_APPS
gunicorn>=20,<21            # WSGI server referenced by Procfile
# (Django automatically pulls in pytz and sqlparse.)
#
# NOTE: gunicorn (WSGI) does not serve WebSockets. `python manage.py runserver`
# serves them automatically when channels is installed. For a production ASGI
# server with WebSocket support, run daphne instead, e.g.:
#   daphne -b 0.0.0.0 -p 8000 frontend_server.routing:application
